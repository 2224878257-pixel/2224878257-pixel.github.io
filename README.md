# 老侯个人网站 V5 · Zara 极简统一版

这版重点：

- 不再使用毛笔字、宋体或“传统中文博客”视觉，统一现代无衬线字体
- 首页尽量接近 Zara Zhang 的“文章优先”逻辑：窄内容区、文章流、大留白
- 全站统一中文菜单：文章 / 案例 / 工具 / 关于
- 所有子页面和详情页全部使用同一套样式，不再继承旧的 AI × Growth / Projects / Writing / Workflows 页面
- 原 `/workflows/` 页面直接跳转 `/tools/`
- 关于页提供公众号 / 小红书 / 抖音二维码，以及 X / 邮箱 / GitHub
- 首页把公众号 / 小红书 / 抖音 / X / 邮箱放在介绍下方，明显但不做成广告栏

## 重要：部署时必须清理旧文件

让 Codex 执行以下操作：
1. 删除仓库中旧的 `articles/`、`cases/`、`tools/`、`workflows/`、`about/` 目录。
2. 删除旧 `index.html`。
3. 再把本目录所有文件完整复制到仓库根目录。
4. 确认 `assets/` 下三个二维码文件一起上传。
5. 提交并 push 到 `main`。
6. 部署后检查 `/`, `/articles/`, `/cases/`, `/tools/`, `/about/` 五个地址，确认导航和样式一致。

不要“合并旧目录”，必须先删除旧目录再复制，否则旧英文页面会继续存在。
