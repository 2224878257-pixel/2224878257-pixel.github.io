ROI一直上不去？我做投放8年，总结出这5个账户诊断步骤

老侯聊增长公众号文章归档

很多投手，我敢说压根不会诊断账户。

当你遇到这种情况：你的账户跑了半个月，消耗也挺稳定，每天也有转化，可你的ROI就是上不去。

这是为什么？

很多投手的第一反应就是：降出价、换素材、关广告、重新搭建广告。

结果是折腾半天，消耗降下来了，ROI也没变，接着这样折腾，账户直接跑不动了。

你苦思冥想，找不出问题在哪儿？

按我的经验，你的问题不一定是动作错了，有可能是诊断顺序错了。

投放诊断账户有个原则：先通链路，再谈优化；先纠偏，再放量。 

什么意思呢？

就是你链路都没跑对，这就像水管已经漏了，你还在调水压，越调越乱。

那可不是你的ROI上不去吗。

今天我分享一下我总结的投放诊断五个步骤，可能会解决你不会诊断的问题。

第一步、先确认链路对不对

这个尤其是一些新项目的投放，问题最容易出在这里。

当看到数据不好的时候，只会盯成本、点击率、转化率。

问题是如果你连正常链路都不知道对不对，就直接看数据，很容易看偏。

不同产品的投放链路完全不一样。

游戏、电商、线索、短剧、小说、App下载等产品，对应的优化目标、转化路径、回传方式、回收周期都不一样。

所以诊断的第一步，不是看后台数据，而是先把正确的链路画出来。 

至少你要搞清楚：

产品类型是什么？

全链路路径是什么？

账户优化目标是什么？

回传方式是什么？

归因窗口怎么算？

模型学习期有多长？

比如一条链路可能是：曝光 → 点击 → 落地页 → 注册 → 激活 → 付费 → 回传。

也可能是：曝光 → 点击 → 表单 → 加微 → 沟通 → 到店 → 成交。

投放链路不一样的话，判断逻辑就不一样。 

这一步你搞不清楚，后面的分析都是错的。

第二步、找到行业锚点

很多投手判断数据好坏，纯粹靠感觉，总认为投放就是玄学。

看到成本高了，就说素材不行；看到ROI低了，就说账户异常。

问题是，你判断的这些问题，依据在哪里？有什么标准？

像一些行业的点击率就是低，有些产品的注册成本就是很便宜，有些项目的ROI当天的就是不高，得看7日、14日回收。

所以第二步，我们要学会找锚点：

同品类CPA、CPI、表单成本大概多少？

点击到注册、注册到付费的正常转化率是多少？

这个品类看当天ROI，还是看3日、7日、14日回收？

这些数据可以来自直客、服务商、行业报告、同行交流、历史账户等渠道。

没有锚点，你连账户到底差在哪里都说不清。 

最后只能说一句：ROI不好，继续优化。

但优化哪一环？

先改什么？

后改什么？

你都答不上来，就是在乱动。

第三步、把回收差拆解到每一环

你要知道，ROI低只是结果，不是原因。 

我们分析的时候要做的，是把ROI低为什么低拆解到投放链路的每一环。

你可以拉取近半个月的投放数据，按日期、广告、版位、素材维度拆解来看：曝光 → 点击率 → 到达率 → 注册率 → 激活率 → 付费率 → 回传率 → ROI。

然后把每一环跟行业的基准或者历史正常值做一下对比，看是哪一环明显偏离的。

点击率低，可能是素材吸引力不够。

点击率正常，到达率低，可能是落地页加载慢或跳转异常。

到达率正常，注册率低，可能是卖点不清楚或门槛太高。

注册率正常，付费率低，可能是人群不准或承接有问题。

付费正常，平台后台回传少，可能是回传链路有问题。

诊断ROI，我们不能只看总消耗和总回收，而要像查水管一样，一段一段地查。

这里还有个要注意的，需要重点看这两个方面：

一个是回传的数据。 客户后台和广告后台长期对不齐，根因很可能不在素材和出价，而在回传。

另一个是操作日志。 频繁调价、改定向、开关广告，都有可能打断模型学习。

很多的账户不是刚开始就差，而是被频繁的操作搞坏的。

第四步、挖根因，不要停在表面

当定位到账户异常的环节时，还要继续问：为什么？

在实战中，ROI上不去，常见的原因主要有这五个。

1、回传方向错误

账户跑的是激活，回传的却是付费；或者想跑付费，但样本太少，模型根本学不动。目标和信号不匹配，模型一定会偏。

2、回传数据缺失

漏传、错传、延迟回传，都会让平台拿不到完整样本，模型学习自然不稳定。

3、模型学习被打断

新建广告前72小时，本来就是探索期。这个阶段频繁调价、改定向、关停重启，相当于不断给模型按重置键。

4、出价和目标错配

前期只适合跑注册、激活，你却按付费成本压出价；或者已经有付费数据了，还一直跑浅层目标，都会让模型找错人。

5、素材竞争与重复竞争

很多素材刚开始能跑，是因为人群新鲜、卖点有效。但是跑的时间久了，用户疲劳，点击率和转化率都会下滑。

这个时候如果只是用老素材搭建在新广告，那么新广告和老广告竞争的是同一流量池。

最后就是新广告起不来，老广告也被拖累了。

这种情况，调出价没用。

要做素材差异化，而且不是改几个字，而是前5秒、封面、标题、卖点、脚本结构都要拉开。 

素材重复竞争，本质不是素材数量不够，而是有效差异不够。

第五步、改完以后，给模型时间

很多账户不是没改对，而是改完后没给系统时间。

今天刚调整，明天ROI没起来，马上又改。

结果每次都只跑半截，模型永远没有完整学习周期。

所以改完后，至少要做好这三件事。

1、设立观察期 

一般调整后至少观察7天；小游戏、App、短剧、小说这类回收周期更长的项目，建议看10到14天。

2、盯趋势，不要盯单日

不要只看某一天ROI，要看点击率、到达率、注册率、付费率、回传率有没有往好的方向走。

3、提前同步预期

告诉客户或上级，调整期成本波动、转化不稳定很正常，ROI不一定马上提升。

不然的话，账户很容易陷入死循环：数据波动 → 继续调整 → 模型中断 → 数据更差 → 再继续调整。

很多时候，ROI上不去，不是我们投手不努力，而是诊断的顺序错了。

大家以后再遇到账户ROI死活上不来，不要急着动账户。

先把链路画出来，把数据拆开，把根因挖出来。

只有先纠偏，再优化，账户才有机会真正跑起来。
